# Chicago Farmers Markets 2026 

A small in-progress project for an RCDS workshop. 

Get familiar with the project by reading:

- `SPEC.md` — what the report is supposed to contain
- `DECISIONS.md` — choices already made, and why
- `SOURCES.md` — where the data came from

And then looking at the current output.

## Exercise

There are several different types of feedback you could work on with the current code:

- Errors with how the data is displayed
- Decisions that could be changed
- Implementing specified features that aren't done yet
- Asking exploratory questions about things you see in the report
- Expanding scope and asking for new features, style, etc.

Fork this repository if you want to work online, or if you want to practice pulling and pushing with a remote.  Otherwise download or clone the repository onto your laptop and just work with the files locally.  

Then practice giving your AI coding agent feedback and direction.  

## Running it

Python 3, standard library only. No install step, no server, no network.

```
python3 build_report.py
```

That writes `report.html` in this folder. Open it by double-clicking it, or
with `open report.html` (macOS) / `start report.html` (Windows).

Re-run the script after any change and reload the page in your browser.
