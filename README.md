# Chicago Farmers Markets 2026 — Starter Repo

A small in-progress project built by an earlier AI session. Before touching
anything, read:

- `SPEC.md` — what the report is supposed to contain
- `DECISIONS.md` — choices already made, and why
- `SOURCES.md` — where the data came from

## Running it

Python 3, standard library only. No install step, no server, no network.

```
python3 build_report.py
```

That writes `report.html` in this folder. Open it by double-clicking it, or
with `open report.html` (macOS) / `start report.html` (Windows).

Re-run the script after any change and reload the page in your browser.
